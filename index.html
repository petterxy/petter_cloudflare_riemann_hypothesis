这个页面在做什么？

黎曼猜想（1859）：ζ(s) 的所有非平凡零点都落在临界线 Re(s) = ½ 上。它是数学中最重要的未解难题之一，悬赏 100 万美元（Clay 千禧年难题）。

本页把猜想变成一场无限延续的数值实验：用 Hardy Z 函数沿临界线向上扫描。Z(t) 是实值函数，它的每个变号点都对应一个零点 ρ = ½ + it。小 t 区间用 Euler–Maclaurin 公式精确计算 ζ(½+it)，大 t 区间用 Riemann–Siegel 公式（含 C₀、C₁、C₂ 修正项）快速计算；检测到变号后用二分法把零点精化到 10⁻¹¹。只要页面开着，搜索就永远继续。

诚实声明：人类已数值验证超过 10¹³ 个零点全部在临界线上，但猜想至今没有被证明——本页面是数值探索与可视化，不是证明。纯静态单文件，无任何外部依赖，可直接部署到 Cloudflare Pages / GitHub Pages。双精度浮点下可推进至 t ~ 10⁸。
