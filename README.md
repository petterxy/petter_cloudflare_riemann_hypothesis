# 黎曼猜想 · 无限延续

沿临界线 Re(s) = ½ 实时搜索 ζ(s) 非平凡零点的无限数值可视化。打开 `index.html`，就能看到零点一个接一个被发现、沿临界线无限上升的过程。

## 特性

- **临界线视角**：零点 ρ = ½ + it 以金点标记，随扫描高度 t 无限上升
- **Hardy Z(t) 波形**：实时波形，每次穿越零轴对应一个零点
- **实时统计**：当前高度、零点计数、最新零点、理论计数 θ(t)/π+1 对照
- **交互控制**：暂停 / 继续 / 重置 / 速度调节（1–40 t/秒）
- 纯静态单文件，零外部依赖；后台标签页自动降速续跑，搜索不中断

## 算法

- t < 60：Euler–Maclaurin 公式精确计算 ζ(½+it)（误差 ~10⁻¹³）
- t ≥ 60：Riemann–Siegel 公式，含 C₀、C₁、C₂ 修正项（误差 <10⁻⁵ 且随 t 递减）
- 变号检测 + 二分法精化零点至 10⁻¹¹

## 部署

纯静态页面，无需构建：

- **Cloudflare Pages**：连接本仓库，构建命令留空，输出目录填 `/`
- **GitHub Pages**：Settings → Pages → main 分支根目录

## 声明

人类已数值验证超过 10¹³ 个零点全部位于临界线上，但黎曼猜想至今未被证明。本页面是数值探索与可视化，不是证明。
